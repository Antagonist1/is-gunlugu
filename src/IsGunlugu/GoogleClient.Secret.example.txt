To build a copy that can connect Google Drive, create GoogleClient.Secret.cs next to this file with:

namespace IsGunlugu;

internal static partial class GoogleClient
{
    static partial void LoadSecret(ref string secret) => secret = "GOCSPX-...";
}

The secret comes from Google Cloud Console > APIs & Services > Credentials > the desktop OAuth client.
GoogleClient.Secret.cs is listed in .gitignore and must never be committed.
Without it the program builds and runs; only "Drive'a bağlan" says this copy has no Google key.
